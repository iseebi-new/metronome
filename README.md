# 🥁 変拍子メトロノーム

セクションごとに拍子・テンポを設定できる、ブラウザで動くギター練習用メトロノーム。
イントロは4/4、Aメロは3/4、サビは7/8…という**曲中に拍子が変わる曲**にそのまま対応します。

**▶ 今すぐ使う: https://iseebi-new.github.io/metronome/**

単一HTMLファイル・外部依存ゼロ・オフライン動作。サーバーもインストールも不要です。

---

## できること

| 機能 | 説明 |
|------|------|
| セクション設定 | 名前 / 小節数 / 拍子(分子=拍数、分母=2・4・8) / BPM をセクションごとに設定 |
| 全曲モード | 全セクションを通して1曲分ループ再生 |
| セクションループ | そのセクションだけを反復練習(🔁ボタン) |
| 部分再生 | セクションの行をクリック → その先頭から再生(▶単独ボタンでも可) |
| テンポ倍率 | 25〜200%。曲全体を一括で遅く/速く(覚えるまで遅く→徐々に上げる、に便利) |
| カウント音 | クリック音 / 日本語音声「1,2,3…」/ 両方 / 無音 |
| 表示 | 拍ごとのランプ + 現在のセクション・小節・拍・拍子・BPM |
| 保存 | ブラウザに複数曲保存(localStorage)、JSON書き出し/読み込みで端末間コピー |

## 基本の使い方

1. **曲名を入力**(例: My Song)
2. **セクションを設定**
   - 初期状態で「イントロ 4/4」「Aメロ 3/4」が入っています
   - 「＋セクション追加」で行を増やし、名前・小節数・拍子・BPMを入力
   - 「複製」「削除」で編集。行の ⠿ をドラッグで並べ替え
3. **▶ ボタンで全曲再生** — セクションをまたぐと拍子・BPMが自動で切り替わります
4. **苦手なセクションだけ** → その行の「🔁ループ」でその部分だけ反復
5. **テンポが速すぎる** → 「全体テンポ倍率」を70%などに下げて練習

### 変拍子の設定例

| 例 | 分子 | 分母 | 意味 |
|----|-----|------|------|
| 5/4 | 5 | 4 | 4分音符5拍で1小節 |
| 7/8 | 7 | 8 | 8分音符7つで1小節(8分=1拍としてカウント) |
| 6/8 | 6 | 8 | 同上 |
| 3/4 | 3 | 4 | 通常のワルツ |

小節頭の拍は高めのクリック音、拍頭(分母=8のときは2拍ごと)は中音、それ以外は低音で区別できます。

## 保存と持ち運び

- **💾ブラウザに保存** — 現在の曲をlocalStorageに保存(端末・ブラウザごとに独立)
- **⬇JSON書き出し / ⬆JSON読み込み** — ファイルで持ち運び(PC→iPhoneなど)

## iPhone / スマホでの使い方

1. Safariで https://iseebi-new.github.io/metronome/ を開く
2. 共有ボタン → **「ホーム画面に追加」** → アイコンからフルスクリーン起動
3. ⚠️ **マナースイッチ(サイレントモード)を解除しないと音が出ません**
4. ⚠️ 画面がスリープすると音が止まるので、練習中は画面オンに
